# Windows 单文件发行版

`dist/XinlePriceDashboard-Electron.exe` 面向 Windows 10 / 11 64 位。它包含 Electron 桌面窗口、项目页面、Node.js、Patchright 和采集用 Chromium，目标电脑不需要安装开发环境或浏览器。界面由 Electron 显示，不出现 Chrome 测试版横幅。

## 使用

1. 关闭旧版看板，把 `XinlePriceDashboard-Electron.exe` 复制到目标电脑并双击。
2. 启动时会解压内置环境，然后打开独立的 Electron 看板窗口。
3. 首次使用时点击「登录配置」，保存该电脑需要使用的账号密码；升级后会继续使用原有配置。
4. 点击「手动刷新价格」采集并保存最新数据；采集全程无头运行，不弹出浏览器，仍使用直连访问票务网站。
5. 使用「旅游地区」按钮切换景区。已有「北京环球度假区」数据时默认选中该地区，否则显示全部地区；各景区的报价独立比较。
6. 切换「列表方式」或「日期方式」。列表按同一地区、同一天、同一票种的价格排序；日期方式显示每一天的最低可用报价，点击有价格的日期可查看当天渠道详情。没有可用报价显示「暂无」，不会当作零元价。
7. 票种分为「1日成人」「1日儿童」「1.5日成人」「1.5日儿童」。无法确认的渠道保留在「待设置」，可进入「票种设置」按旅游地区筛选，再按名称、编号查找并修改。
8. 顶部「导出 Excel」保存全部已收录地区、渠道和日期，不受当前页面筛选影响；「导出 JSON」仍保留完整价格数据。导出读取已保存的数据，不会重新采集；需要最新报价时先完成手动刷新。
9. 关闭看板窗口会退出本次启动的后台服务和正在运行的采集。

发行包不包含开发电脑上的账号、密码、历史价格或浏览器登录状态。

## 本地票种设置

票种设置按渠道 ID 保存，选择四种票种之一并点击「保存设置」后立即生效。本地设置优先于接口的票种和自动识别结果，手动刷新、关闭重开或更换新版 EXE 都不会覆盖它；渠道暂时下架后重新出现也会沿用同一 ID 的本地设置。

选择「跟随接口」并保存，会取消该渠道的本地覆盖，恢复自动识别。无法确定游玩时长或适用人群的渠道显示为「待设置」，不会参与四种已分类票种的最低价排名。旧版本保存的成人、儿童设置分别沿用为「1日成人」「1日儿童」，可在设置窗口调整为实际票种。

## Excel 导出内容

导出的 `.xlsx` 文件包含以下四张工作表；生成文件不需要安装 Office。

| 工作表 | 内容 |
| --- | --- |
| 渠道每日最低价 | 每个渠道一行、每个日期一列，包含旅游地区、票种、渠道 ID、完整名称和票种来源。 |
| 每日票种最低价 | 按地区、票种、日期汇总最低可用报价，并列最低时保留全部渠道。 |
| 报价明细 | 保留全部已保存的每日价格记录及库存、可用状态，方便核对。 |
| 导出说明 | 记录导出范围、更新时间、价格单位，以及最低价和本地票种设置规则。 |

空白价格表示当日没有可用报价，数字 `0.00` 才代表有效的零元报价。「待设置」渠道仍保留在渠道表和明细中，不参与四类票种的每日最低价汇总。导出失败时会在按钮旁显示原因，页面和已保存数据保持不变。

## 数据目录

默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\XinlePriceDashboard`：

- `data\config\login.json`：用户在页面保存的登录配置。
- `data\config\ticket-types.json`：按渠道 ID 保存的本地票种设置，刷新及重启后继续优先使用。
- `data\output\ticket-prices.json`：最近一次成功的完整价格数据。
- `data\output\ticket-prices.previous.json`：上一次成功数据的备份。
- `electron-profile`：Electron 窗口的独立缓存目录。
- `launcher.log`：桌面启动日志，不记录账号密码。

账号及价格数据和 EXE 文件的位置分离，更新或移动 EXE 不会覆盖已有配置。与上一版 EXE 使用相同的数据目录，关闭旧版后直接运行新版即可继续使用旧配置和价格。复制 EXE 到另一台电脑不会自动携带原电脑的用户数据。旧版的 `runtime`、`ui-profile` 目录不会被新版修改。服务只监听 `127.0.0.1`，自动选择空闲端口，不要求管理员权限。

## 开发机重新构建

开发机需要 Windows x64、Node 24、已安装项目依赖及与 Patchright 对应的 Chromium，不再需要 .NET SDK。运行：

```powershell
npm run build:exe
```

构建脚本只复制允许的程序目录，解引用 pnpm 链接并打包完整依赖，排除配置、输出、日志和开发缓存，再用 electron-builder 生成 portable EXE。地区筛选、两种视图、票种设置和 Excel 导出所需的 `web` 页面及 `lib` 模块均随程序打包。Excel 写入使用内置 Node.js，不需要额外安装 Excel 运行库。

生成的 SHA-256 校验文件用于核对复制后的 EXE 是否完整。`build/electron-release` 是构建中间产物；分发时复制 `dist` 中最终 EXE 即可，也可同时提供 `使用说明.md` 和 `.sha256` 校验文件。EXE 自带运行依赖，无需同时复制源码或 `node_modules`。

开发调试桌面窗口：`npm run desktop`。验证独立运行和持久化：`npm run test:exe`；加 `-- --with-refresh` 会使用开发机已保存的账号执行实际无头采集，结束后删除隔离测试目录中的账号副本。

诊断参数（普通使用无需填写）：

```text
XinlePriceDashboard-Electron.exe --data-root C:\Temp\XinleTest --no-window
```

此模式不打开看板窗口，后台服务的本地地址会写入指定目录的 `session.json`。不要把真实登录配置加入源码或分发文件。

桌面窗口采用 [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)，打包采用 [electron-builder portable](https://www.electron.build/nsis.html)。窗口启用沙箱、上下文隔离及同源限制，参见 [Electron 安全说明](https://www.electronjs.org/docs/latest/tutorial/security)。采集浏览器运行文件随程序分发。
